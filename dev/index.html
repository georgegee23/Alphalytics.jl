Alphalytics.alpha — Function
alpha(returns::TimeArray, benchmark_returns::TimeArray, risk_free_rate::Number = 0.0) -> Vector{Float64}

Compute each asset's return in excess of what its beta alone would predict.

alpha = mean asset return - [risk-free rate + beta * (mean benchmark return - risk-free rate)]

Positive alpha is the part of performance not explained by simply taking on benchmark exposure, which is the part attributable to skill or to the factor itself.

Arguments

  • returns::TimeArray: Periodic returns as decimals, one column per asset.
  • benchmark_returns::TimeArray: Single-column benchmark returns on the same timestamps.
  • risk_free_rate::Number: Per-period risk-free rate (default: 0.0).

Returns

  • Vector{Float64}: One alpha per column, in column order, expressed per period in the same units as the input returns.

Throws

  • ErrorException: If the timestamps of the two TimeArrays do not match.
  • AssertionError: If either TimeArray contains NaN values.

Notes

  • risk_free_rate is a per-period rate, matching the frequency of the returns.

annualized_downside_deviation(returns::TimeArray, mar::Number = 0, periods_per_year::Int = 52;
                              corrected::Bool = true) -> Vector{Float64}

Compute the annualized downside deviation of each asset.

The periodic figure from downside_deviation scaled by the square root of periods_per_year.

Arguments

  • mar::Number: Per-period minimum acceptable return (default: 0).
  • periods_per_year::Int: Number of periods in a year (default: 52, i.e. weekly data).
  • corrected::Bool: Apply Bessel's correction (default: true).

Returns

  • Vector{Float64}: One annualized downside deviation per column, in column order.

Throws

  • AssertionError: If returns has fewer than two data points, or periods_per_year is not positive.

Notes

  • mar is a per-period threshold. To use an annual target, divide it by periods_per_year before passing it in.

Compute the compound annual growth rate of each asset.

The returns are compounded into a total growth figure, then rescaled to a one-year horizon, giving the annual rate that would have produced the same result over the sample.

Arguments

Throws

annualized_stdev(returns::TimeArray, periods_per_year::Int) -> Vector{Float64}

Compute the annualized volatility of each asset.

The periodic standard deviation from stdev is scaled by the square root of periods_per_year, the standard convention for putting volatility on an annual footing.

Arguments

  • returns::TimeArray: Periodic returns as decimals, one column per asset.
  • periods_per_year::Int: Number of periods in a year (252 daily, 52 weekly, 12 monthly).

Throws

  • AssertionError: If returns contains fewer than two data points.

Alphalytics.beta — Method
beta(returns::TimeArray, benchmark_returns::TimeArray) -> Vector{Float64}

Compute each asset's sensitivity to the benchmark.

beta = cov(asset returns, benchmark returns) / var(benchmark returns)

A beta of 1 moves with the benchmark, above 1 amplifies it, below 1 damps it, and a negative beta moves against it.

Arguments

  • returns::TimeArray: Periodic returns as decimals, one column per asset.
  • benchmark_returns::TimeArray: Single-column benchmark returns on the same timestamps.

Returns

  • Vector{Float64}: One beta per column, in column order. A benchmark with zero variance yields NaN.

Throws

  • ErrorException: If the timestamps of the two TimeArrays do not match.
  • AssertionError: If either TimeArray contains NaN values. Drop or fill them first.

Alphalytics.down_capture — Function
down_capture(returns::TimeArray, benchmark_returns::TimeArray, mar::Number = 0) -> Vector{Float64}

Compute how much of the benchmark's losses each asset absorbed.

Only the periods where the benchmark fell below mar are considered; the asset's mean return over those periods is divided by the benchmark's. Lower is better: 0.8 means the asset lost only 80% as much as the benchmark did in down markets, while above 1 means it lost more.

Arguments

  • returns::TimeArray: Periodic returns as decimals, one column per asset.
  • benchmark_returns::TimeArray: Single-column benchmark returns on the same timestamps.
  • mar::Number: Threshold below which the benchmark counts as down (default: 0).

Returns

  • Vector{Float64}: One down capture ratio per column, in column order. All NaN if the benchmark never fell below mar, and NaN for a benchmark whose mean down return is zero.

Throws

  • ErrorException: If the timestamps of the two TimeArrays do not match.
source
Alphalytics.downside_deviation — Function
downside_deviation(returns::TimeArray, mar::Number = 0; corrected::Bool = true) -> Vector{Float64}

Compute the volatility of the losses only, ignoring upside moves.

Plain standard deviation punishes large gains as much as large losses. Downside deviation looks solely at returns falling below the minimum acceptable return, which matches how investors actually experience risk. It is the denominator of the Sortino ratio.

Arguments

  • returns::TimeArray: Periodic returns as decimals, one column per asset.
  • mar::Number: Minimum acceptable return; only returns below this count (default: 0).
  • corrected::Bool: Apply Bessel's correction, dividing by n-1 rather than n (default: true).

Returns

  • Vector{Float64}: One downside deviation per column, in column order. A column with no returns below mar yields 0.0.

Throws

  • AssertionError: If returns holds non-numeric data.

Notes

  • The deviations are divided by the count of below-MAR observations, not by the total number of periods.

Alphalytics.mean_autocor — Method
mean_autocor(factors::TimeArray, maxlag::Int) -> Vector{Float64}

Compute the average autocorrelation of factor scores across securities.

Each security's own score history is autocorrelated, then the results are averaged across securities lag by lag. High autocorrelation means scores are persistent, which implies low turnover; low autocorrelation means the factor reshuffles its rankings quickly.

Arguments

  • factors::TimeArray: Factor scores, one column per security.
  • maxlag::Int: Maximum lag for which to compute the autocorrelation.

Returns

  • Vector{Float64}: Mean autocorrelation per lag, of length maxlag + 1. The first entry is lag 0 and is therefore always 1.0; lag k sits at index k + 1.
  • If no security has more than maxlag non-NaN scores, a warning is issued and a vector of maxlag NaNs is returned.

Details

  • NaN scores are dropped per security before the autocorrelation is computed, and securities with maxlag or fewer remaining observations are excluded entirely.

overall_capture(returns::TimeArray, benchmark_returns::TimeArray, mar::Number = 0) -> Vector{Float64}

Compute the capture ratio: upside captured relative to downside suffered.

overall capture = up capture / down capture

This condenses up_capture and down_capture into one number. Above 1 is favourable, meaning the asset keeps more of the benchmark's gains than of its losses.

Returns

  • Vector{Float64}: One overall capture ratio per column, in column order.

Notes

  • The ratio is hard to read when down capture is negative, which happens when an asset gains on average while the benchmark falls. Inspect the two legs separately in that case.

performance_table(ta_returns::TimeArray, benchmark_returns::TimeArray, periods_per_year::Int,

Alphalytics.quantile_turnover — Method
quantile_turnover(quantile_ta::TimeArray, target_quantile::Number) -> TimeArray

Calculate how much of a single quantile's membership is replaced each period.

A security counts as unchanged when it sat in target_quantile last period and still does this period. Turnover is the fraction of the current members that are new arrivals, so 0.0 means the bucket is unchanged and 1.0 means it turned over completely.

Arguments

  • quantile_ta::TimeArray: Quantile assignments, one column per security, ordered by time.
  • target_quantile::Number: The quantile whose turnover is measured.

Returns

  • TimeArray with three columns, starting one period after the input because the first period has nothing to compare against:
    • Turnover: Fraction of the quantile's members that changed from the previous period.
    • NoChange: Count of members carried over from the previous period.
    • Total: Count of securities in the quantile this period.

Throws

  • ArgumentError: If quantile_ta has fewer than 2 time points.

Notes

  • A period in which no security sits in target_quantile divides by zero and yields NaN for that period's turnover.
source

This is the linear counterpart of rows_spearmanr. It measures the strength of the linear relationship between factor score and realised return, so unlike the rank IC it is sensitive to outliers and to the scale of the factor.

sortino_ratio(returns::TimeArray; risk_free_rate::Number = 0.0, mar::Number = 0.0,

Alphalytics.spearman_factor_decay — Method
spearman_factor_decay(factors::TimeArray, returns::TimeArray, max_lags::Int) -> Vector{Pair{Int, Float64}}

Measure how quickly a factor's predictive power decays as it ages.

For each lag from 1 to max_lags the factor is shifted forward in time, re-aligned with the returns it would then be predicting, and the mean cross-sectional rank IC is taken. A series that holds its IC over many lags is slow to decay and tolerates less frequent rebalancing.

Alphalytics.tail_ratio — Function
tail_ratio(returns::TimeArray, benchmark_returns::TimeArray, percentile::Float64 = 0.95) -> Vector{Float64}

Compare how each asset behaves in the benchmark's best periods versus its worst.

tail ratio = mean return in the benchmark's best tail / |mean return in its worst tail|

The tails are defined by the benchmark, not by the asset's own returns, so this measures behaviour in extreme markets rather than the shape of the asset's own distribution. Above 1 means the asset gains more in the best periods than it loses in the worst.

  • benchmark_returns::TimeArray: Single-column benchmark returns on the same timestamps.
  • percentile::Float64: Upper tail cutoff (default: 0.95). The lower tail is its complement, so the default compares the benchmark's best 5% of periods against its worst 5%.

Returns

  • Vector{Float64}: One tail ratio per column, in column order. All NaN if either tail is empty, and NaN for a column whose mean worst-tail return is zero.

Throws

  • ErrorException: If the timestamps of the two TimeArrays do not match.
